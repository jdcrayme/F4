# QC Pass — F4 Repository

## Findings (diagnosis first)

**1. Flight plans covering the map — confirmed.** Three separate polyline passes draw for every flight every frame: static waypoint polylines (`f4-world-viewer/src/canvas.cpp:599-612`, gated only by `show_waypoints`), live session routes (`canvas.cpp:719-743`, gated only by `show_live_routes`), and mission→target / package→element links (`canvas.cpp:1021-1106`, always drawn, selection only bolds them). The selection state (`sel_kind`/`sel_entity`, `viewer_state.hpp:429-431`) is already read inside all three loops, and there's a clean precedent for selection-gated drawing: the ground-layout overlay (`canvas.cpp:1200-1205`). ATO row clicks already set selection (`campaign_qc_view.cpp:322-330`), so gating "just works" from the ATO window.

**2. Speed ratio control — wiring is intact; the bug is feedback.** Radios → `session_runner->set_speed()` → atomic → worker multiplies wall time → `CampaignSession::advance()` (`campaign_session.cpp:433-481`). Root causes of "does nothing": (a) sessions start **paused**, so presets visibly do nothing until Play; (b) in a Debug build the sim does ~330–540 ticks/sec (noted in CHANGES.md C5), so 10x/60x/240x all produce the identical effective ~6–9x rate — excess time is silently dropped (`campaign_session.cpp:474-478`) and the only hint is a tiny "(time-dilated)" text; (c) the static Campaign window's clock never moves (it reads the frozen save), so it's easy to watch the wrong clock.

**3. Missing 3D views — confirmed, plumbing already exists.** The Inspector 3D tab hard-rejects non-objective selections (`ground_layout_3d.cpp:256-260`). Meanwhile the map's zoom>6 pass already renders live/parked aircraft and deaggregated vehicles as real vis_type meshes (`canvas.cpp:870-1001`), every session entity carries `VisualModelComponent::vis_type` + transform, squadrons/units expose `class_table_index` (`entity.hpp:407,483`), `ClassTable::vis_type_for()` resolves models, and shared mesh/texture caches + `draw_vis_type_mesh()` (`feature_mesh.hpp`) are ready. Gap is pure wiring. Parked aircraft and vehicles are also not click-selectable today.

**Full-sweep extras found:** three no-op checkboxes (draw code commented out at `canvas.cpp:587-662`, but toggles still exposed in both View menu `imgui_panels.cpp:161,163,167` and Layers panel `:325,327,329`, with a falsely "Now wired up" comment at `:164-166`); Write-Result-JSON logic duplicated (`imgui_panels.cpp:224-239` vs `campaign_session_view.cpp:641-655`); pause flip implemented 3× (`campaign_session_view.cpp:453-462`, `viewer_app.cpp:285-291`, `imgui_panels.cpp:206-215`); stale Campaign-menu auto-open that can never fire (`imgui_panels.cpp:192-196`, checks `impl_->session` right after an async start); "Reset Session" can kill a just-adopted session if async create races a deferred stop (`campaign_session_view.cpp:321-347`); Layers panel missing the Campaign-QC and Live-session toggle groups; `Impl::units()` rebuilds a vector ~4×/frame (`viewer_state.hpp:280-289`); inconsistent 10ft/5ft Z-sink constants (`ground_layout_3d.cpp:100` vs `:522,546,577`); parking-spot modulo stacks aircraft on one spot (`campaign_bridge.cpp:1559-1568`); unused `(void)uc2` (`inspector_panel.cpp:664-666`) and `(void)num` (`ground_layout_models.cpp:670`); dead `draw_ground_grid()` (`ground_layout_3d.cpp:135-154`); `BSpecialXform` billboard TODO (`f4-models/src/geometry_extractor.cpp:690`); README never mentions f4-models-viewer. Git tree is clean; tracked `temp/` archives are intentional.
